中部 / PREFECTURE GUIDE

石川県の
アスベスト調査・届出ガイド

石川県では、通常工事の法定手続に加え、能登半島地震の被災建築物の解体に伴う飛散防止と大気中石綿濃度の監視が地域特有の重要事項です。災害解体の制度は対象区域・対象者が限定されるため、通常の民間工事と分けて確認します。

石川県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01能登半島地震の被災地域・解体現場周辺。一般工事の一律測定義務を意味するものではない。

能登半島地震の被災地で継続的に濃度を監視

県は、能登半島地震に伴う被災建築物の解体等を踏まえ、大気中の石綿濃度調査結果を公表しています。被災建物は立入困難や建材の露出があり得るため、通常の改修工事以上に、事前調査可能範囲の記録と作業中の飛散防止が重要です。

根拠[1]
02県所管区域の特定粉じん排出等作業。金沢市内は市の案内を確認。

届出・説明資料に現場体制と周辺状況を反映

県の手引きは、敷地・建物配置、周辺状況、元請・下請の現場責任者などを含む実務資料を案内しています。住宅密集地や避難施設に近い工事では、隔離・集じん排気だけでなく、搬出経路と緊急連絡体制も具体化します。

根拠[2]
03能登半島地震に関する公費解体の対象市町・対象家屋のみ。

災害公費解体は通常工事と別の申請体系

被災家屋の公費解体は、対象市町、被害認定、所有関係、申請期限など固有の要件があります。石綿関係法令の手続が不要になるわけではなく、公費解体の受付と環境法令の届出を別々に整理します。

WHERE TO FILE

届出先は工事場所から確定する

金沢市内は金沢市、その他の区域は石川県の所管窓口へ相談します。被災家屋の公費解体・自費解体支援は工事地の市町が窓口となる場合があります。

BEFORE WORK

着手前チェック

  1. 1金沢市所管か県所管かを確認し、届出窓口を一本化する
  2. 2被災建物では立入可能範囲と未調査範囲を図面・写真で明示し、状況変化時に再調査する
  3. 3住宅、避難所、学校等との位置関係を踏まえて飛散防止・搬出経路・周知方法を決める
  4. 4公費解体等を利用する場合も、大気・労働・廃棄物の手続を別途確認する

SUBSIDY CHECK

補助制度は契約・着工前に確認

能登半島地震に伴う公費解体・自費解体関連の支援は、対象災害、対象市町、申請期限が限定される制度です。通常の民間工事へ一般化せず、工事地の市町に現行の対象要件と受付状況を確認してください。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04石川県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
