中部 / PREFECTURE GUIDE

静岡県の
アスベスト調査・届出ガイド

静岡県では、静岡市・浜松市など複数の市が大気関係の窓口となり、工事場所によって提出先が変わります。支援制度は市町ごとに実施状況が異なり、補助金に加えて、条件を満たす県内中小企業向けの融資制度も選択肢になります。

LOCAL DIFFERENCES

静岡県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01静岡県内の解体・改造・補修工事。

複数市が独自窓口となるため提出先確認が重要

県内は県所管だけでなく、静岡市、浜松市、沼津市、富士市など市が大気汚染防止法の窓口となる区域があります。同一企業の複数現場でも提出先が変わり得るため、現場住所ごとに確認します。

根拠[1][4]
02一覧に掲載された市町の対象建築物。当該年度の市町要綱・予算が優先。

補助の有無を市町別一覧で確認できる

県は、吹付けアスベスト等の分析調査・除去等に関する市町の補助実施状況を公表しています。分析のみ、除去まで、制度なしなどが分かれるため、県内一律の支援として扱わないことが重要です。

根拠[2]
03要件を満たす県内中小企業者。個人住宅向け補助ではない。

中小企業は融資制度の対象となる場合がある

県の中小企業向け防災・減災強化資金では、認定要件を満たす吹付けアスベスト対策が融資対象となる場合があります。補助金ではなく返済が必要な融資であり、認定と金融審査を分けて確認します。

根拠[3]

WHERE TO FILE

届出先は工事場所から確定する

静岡市、浜松市、沼津市、富士市などは市の担当窓口、その他は静岡県の健康福祉センター等が窓口となります。最新の所管は環境省・県の連絡先一覧で確認します。

BEFORE WORK

着手前チェック

  1. 1現場住所から県・市のどちらが大気関係窓口か特定する
  2. 2市町補助の対象が分析、除去、封じ込め、囲い込みのどこまでか確認する
  3. 3補助決定前の契約・着工が認められるかを必ず確認する
  4. 4融資を利用する場合は、補助金との違い、認定要件、返済条件を確認する

SUBSIDY CHECK

補助制度は契約・着工前に確認

県が公表する市町別一覧で実施状況を確認できますが、対象建材や上限額は市町ごとに異なります。中小企業向け県制度は融資であり、一般住宅への給付型補助とは異なります。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04静岡県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
