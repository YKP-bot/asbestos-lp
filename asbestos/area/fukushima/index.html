福島県の
アスベスト調査・届出ガイド

福島市・郡山市・いわき市が各市所管で、その他を県6地方振興局が担当する。県は実施届添付図面を具体化し、令和8年度も工事現場周辺と一般環境の濃度測定を継続する。

LOCAL DIFFERENCES

福島県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01福島県全域

3市と県6地方振興局で所管を分担

福島市・郡山市・いわき市は各市へ、それ以外は県北・県中・県南・会津・南会津・相双の6地方振興局へ提出する。県中地方振興局の所在地は郡山市だが、郡山市内の工事は郡山市環境保全センターが窓口となる点に注意する。

根拠[1]
02福島県所管地域の届出対象特定工事

県実施届は隔離・前室まで図面添付を明示

県の実施届案内は、建築物の配置図と付近状況、作業工程、対象部分の見取図、作業場の隔離状況と前室設置状況を示す見取図を添付書類として明示する。届出作成前に養生・負圧設備の配置を施工計画へ落とす必要がある。

根拠[1]
03福島市内

福島市は施工中に未把握石綿を発見したら計画を都度見直す

福島市の案内は、施工中に事前調査で把握していなかった石綿含有建材等が見つかった場合、その都度作業計画を見直すよう明記している。破壊しないと確認できない箇所を事前調査記録で特定し、発見時の中止・連絡・追加調査手順を決めておく。

根拠[2]
04福島県内（県事業）

令和8年度も県が現場周辺・一般環境の濃度を測定

福島県の令和8年度事業計画は、解体工事現場等で飛散防止対策を指導し、工事現場等周辺と県内一般環境の大気中アスベスト濃度を測定して飛散状況を把握する事業を継続するとしている。

根拠[4]
05福島市内

福島市の調査助成は令和8年度予算で終了扱い

福島市の令和8年度予算資料では、建築物アスベスト調査助成事業費補助金は令和7年度750千円に対し令和8年度0円で「廃目」とされています。旧制度を現行制度として案内しません。

根拠[3]

BEFORE WORK

着手前チェック

  1. 1福島市・郡山市・いわき市か、それ以外の6地方振興局管内かを工事住所で判定する。
  2. 2県所管の実施届では、配置・周辺状況、工程、対象箇所、隔離、前室を示す図面を14日前より十分前に作成する。
  3. 3破壊前に確認できない箇所を事前調査記録へ明示し、施工中の発見時は作業停止、追加調査、計画変更、関係者報告を実施する。
  4. 4県の現場確認や周辺濃度測定を想定し、掲示、調査根拠、点検記録、負圧・集じん排気装置の管理記録を現場に備える。
  5. 5福島市の旧アスベスト調査助成は令和8年度廃目のため、見積の資金計画に補助金を織り込まない。

SUBSIDY CHECK

補助制度は契約・着工前に確認

福島市の建築物アスベスト調査助成事業費補助金は、令和8年度予算資料で0円・廃目。県内他市町村の空き家・改修制度は対象経費が個別に異なるため、アスベスト費用を対象と断定せず所在地自治体へ確認する。

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04福島県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。

福島県のアスベスト工事は、どこへ届け出ますか？

福島県で全国共通ルール以外に確認すべきことは何ですか？

3市と県6地方振興局で所管を分担：福島市・郡山市・いわき市は各市へ、それ以外は県北・県中・県南・会津・南会津・相双の6地方振興局へ提出する。県中地方振興局の所在地は郡山市だが、郡山市内の工事は郡山市環境保全センターが窓口となる点に注意する。 県実施届は隔離・前室まで図面添付を明示：県の実施届案内は、建築物の配置図と付近状況、作業工程、対象部分の見取図、作業場の隔離状況と前室設置状況を示す見取図を添付書類として明示する。届出作成前に養生・負圧設備の配置を施工計画へ落とす必要がある。
