関東 / PREFECTURE GUIDE

神奈川県の
アスベスト調査・届出ガイド

神奈川県の県所管区域では、県生活環境保全条例に基づき、周知計画・濃度測定計画を含む管理計画届、周知実施後の報告、作業中測定の速報、異常時報告、30日以内の完了報告まで一連の手続があります。横浜・川崎など6市は県指針の対象外で、各市の条例・様式を確認します。

LOCAL DIFFERENCES

神奈川県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01横浜・川崎・相模原・横須賀・平塚・藤沢の6市を除く県所管区域

法届と条例の管理計画届を同時に準備

レベル1・2の除去等では、作業開始14日前までに法の届出と条例の石綿排出等作業管理計画等届出書を提出します。条例届には案内・配置・平面・立面図、工程・施工方法、管理体制、周知計画、濃度測定計画、処理委託先資料等が求められます。

根拠[1]
02県条例・指導指針の対象となる除去等工事

周知結果と作業中測定を随時報告

作業前の周知が終わったら速やかに実施状況を報告します。除去作業中の総繊維数濃度は測定日の翌々日の工事開始時までに把握して速やかに報告する運用です。

根拠[1]
03県条例・指導指針の対象となる除去等工事

1本毎リットル超で通報・応急措置・様式報告

周辺の石綿繊維数濃度が1本/Lを超えた場合などの非常時、または総繊維数濃度が1本/Lを超えた場合は、直ちに通報して飛散防止の応急措置を行い、その後速やかに第21号様式の応急措置等報告書を提出します。

根拠[1]
04県条例対象区域の石綿排出等工事

完了後30日以内に写真・測定・点検・マニフェストを報告

発注者または自主施工者は、作業完了から30日以内に第20号様式の完了報告書を提出します。測定結果、作業点検記録、工事写真、産業廃棄物管理票D票またはE票の写しが添付対象です。

根拠[1]
05県が列挙する21市町村にある要件適合建築物

県の含有調査補助は21市町村・建物要件を限定

県の含有調査補助は、逗子市など指定21市町村に所在し、平成元年以前に確認・着工された建築物で、吹付け材、不特定多数利用用途や床面積等の要件を満たすものが対象です。別に、令和8年度の調査者派遣事業も受付中です。

根拠[2][3]

WHERE TO FILE

届出先は工事場所から確定する

県の手続ページと指導指針は、横浜市、川崎市、相模原市、横須賀市、平塚市、藤沢市を除く県内市町村が対象です。6市内は各市担当部署、その他は県政総合センター等が所管します。

根拠[1][2][3][4]

BEFORE WORK

着手前チェック

  1. 1施工地が6市の市所管か県所管かを最初に確認する。
  2. 2周知対象・内容、測定地点、非常時連絡体制を着工14日前より前に固める。
  3. 3周知完了後と作業中測定後の随時報告を工程表に入れる。
  4. 41本/L超過時の停止・通報・応急措置・第21号様式の担当者を決める。
  5. 5完了後30日以内の報告に必要な写真、点検表、測定結果、マニフェストを施工中から整理する。
  6. 6補助制度の21市町村・建築年・用途・面積要件と、契約前手続を確認する。

SUBSIDY CHECK

補助制度は契約・着工前に確認

県の含有調査補助は県内全域ではなく、公式ページに列挙された21市町村と建物要件に限定されます。令和8年度の調査者派遣も対象条件が別です。横浜市・川崎市などは各市制度を確認してください。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04神奈川県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
