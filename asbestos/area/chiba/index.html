千葉県の
アスベスト調査・届出ガイド

千葉県では、特定粉じん排出等作業と事前調査結果報告の窓口が、千葉・船橋・柏・市川・松戸・市原の6市と県の地域振興事務所に分かれます。千葉市には令和8年度の分析調査・除去等補助がありますが、市外へは適用されません。

千葉県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01千葉県内の特定粉じん排出等作業

石綿工事の届出窓口は6市と県地域振興事務所

千葉市・船橋市・柏市・市川市・松戸市・市原市では各市が特定粉じん排出等作業の届出を受理し、その他は県の地域振興事務所が担当します。市川・松戸・市原は2022年4月から市へ移ったため、古い窓口表を流用できません。

根拠[1][2]
02報告対象規模に該当する千葉県内の解体・改修工事

事前調査結果報告も同じ6市区分

石綿事前調査結果報告も、6市は各市、それ以外は県地域振興事務所へ提出する一覧が示されています。紙提出時は、特定粉じん排出等作業の届出先と併せて最新窓口を確認します。

根拠[2]
03千葉市内で市の要件を満たす建築物

千葉市は分析調査と除去等を補助

千葉市は令和8年度、吹付けアスベストまたはアスベスト含有吹付けロックウールが施工された建築物について、分析調査は1棟25万円を上限、除去・封じ込め・囲い込み・一定の除却は費用の3分の2以内を補助すると案内しています。申請前の事前相談が必要です。

根拠[3]

WHERE TO FILE

届出先は工事場所から確定する

千葉市、船橋市、柏市、市川市、松戸市、市原市の工事は各市担当課、それ以外は施工場所を管轄する千葉県地域振興事務所地域環境保全課が、特定粉じん排出等作業と事前調査結果報告を受け付けます。

根拠[1][2][3][4]

BEFORE WORK

着手前チェック

  1. 1施工地が6市の市所管か県地域振興事務所所管かを確認する。
  2. 2特定粉じん排出等作業届と事前調査結果報告の提出先を最新一覧で確認する。
  3. 3県独自の一律の濃度測定・完了報告義務は今回参照した公式資料では確認できていないため、各所管へ最新運用を照会する。
  4. 4千葉市補助を検討する場合は、見積・契約前に建築指導課へ相談する。
  5. 5建設リサイクル法対象工事では、石綿関係手続とは別に受理窓口を確認する。

SUBSIDY CHECK

補助制度は契約・着工前に確認

千葉市は令和8年度の吹付けアスベスト分析調査・除去等補助を案内しています。これは千葉市制度であり、船橋市など他市町には適用されません。県内他地域は所在地の自治体に制度の有無を確認してください。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04千葉県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
