高知県の
アスベスト調査・届出ガイド

高知県は県独自の実施マニュアルに基づき、大規模建築物や大規模除去などで敷地境界・施工区画周辺の大気中アスベスト濃度を測定しています。また高知市内とそれ以外で大気・廃棄物の窓口が分かれ、県の支援は補助金ではなく調査者派遣等として案内されている点を区別する必要があります。

LOCAL DIFFERENCES

高知県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01県が測定対象とする届出工事。高知市域を含む個別の運用は所管へ事前確認。

大規模工事は県が周辺大気を測定

県マニュアルにより、床面積3,000平方メートル以上の大規模建築物、除去面積500平方メートル以上の大規模除去作業、その他飛散のおそれがある事例で、敷地境界または施工区画周辺の大気環境調査を実施しています。

根拠[1]
02高知県内の解体・改修工事。高知市内と市外で所管が異なる。

高知市内は大気も廃棄物も市が窓口

高知市内では大気汚染防止法の届出・報告と石綿廃棄物相談がそれぞれ市の担当課となり、市外では県の窓口に切り替わります。現場住所を基準に、飛散防止と廃棄物の両方の担当を確認します。

根拠[1]
03高知県民間建築物吹付けアスベスト等含有調査事業。対象要件は住宅課へ確認。

県支援は調査者派遣、補助金とは別

県は、多数利用の民間建築物にある吹付けアスベスト等の含有調査について、調査者派遣等の支援事業を案内しています。一方、県ページはアスベスト調査・除去だけを対象とした県の補助金は設けていないと明記しており、両者を混同しないことが必要です。

根拠[1]

WHERE TO FILE

届出先は工事場所から確定する

高知市内の大気汚染防止法関係は高知市環境保全課、廃棄物は高知市廃棄物対策課です。高知市以外は県環境対策課・各福祉保健所等が担当します。

根拠[1][2]

BEFORE WORK

着手前チェック

  1. 1床面積3,000平方メートル、除去面積500平方メートルの県測定基準に該当するか確認する
  2. 2高知市内か市外かで大気・廃棄物それぞれの窓口を確定する
  3. 3県の調査者派遣支援と金銭補助を混同せず、対象要件を住宅課へ確認する
  4. 4周辺測定を見込んだ工程、測定点、漏えい時対応を除去計画へ入れる
  5. 5労働基準監督署の管轄も市町村別に確認し、大防法手続と分けて提出する

SUBSIDY CHECK

補助制度は契約・着工前に確認

県は吹付け材の含有調査について調査者派遣等の支援を案内しています。県のアスベスト専用補助金とは性質が異なり、市町村の耐震・老朽住宅除却等の制度も対象工事が別なので、制度ごとに適用可否を確認してください。

根拠[1][2]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04高知県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
