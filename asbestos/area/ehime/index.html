愛媛県の
アスベスト調査・届出ガイド

愛媛県は県、松山市、愛媛労働局などでアスベスト対策連絡会議を設置しており、環境・労働・市の窓口連携を前提にした確認が必要です。県の最新案内は2026年からの工作物調査資格も強調しているため、建築物だけでなく配管・ボイラー等を含む改修では資格範囲を先に確認します。

LOCAL DIFFERENCES

愛媛県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01愛媛県内の石綿相談・解体等工事。個別手続は各所管へ提出。

県・松山市・労働局等の連絡会議を設置

愛媛県は2005年から、県関係部局、松山市、愛媛労働局などによるアスベスト対策連絡会議を設けています。発注者は環境部局への届出だけでなく、労働安全、建築、廃棄物の各確認を並行して進めます。

根拠[1]
02告示対象の工作物等。設備種類により必要な調査者資格が異なる。

2026年の工作物資格義務化を県ページで更新

県の大気関係情報は、2026年1月から一部工作物の解体・改修時にも資格者による事前調査が必要になることを案内しています。工場設備、配管、ボイラー、煙突等を建築物調査だけで済ませず、工作物調査者の要否を確認します。

根拠[2]
03県内で解体・改修工事を発注する建物所有者等。

発注者が写真記録の提出を求める実務を推奨

県の発注者向け資料は、事前調査費が見積に計上されていること、調査資格、工事後の飛散防止措置と写真記録の提出を確認するよう案内しています。見積比較では除去費だけでなく、調査・記録・完了説明までを仕様化します。

WHERE TO FILE

届出先は工事場所から確定する

松山市内は松山市の大気環境担当、それ以外は県の所管窓口へ確認します。労働基準監督署への計画届・作業届は別系統で、県の連絡会議があることと提出の一本化は同義ではありません。

BEFORE WORK

着手前チェック

  1. 1松山市内か県所管区域かを工事住所で確定する
  2. 2建築物だけでなく設備・配管等の工作物が工事範囲に含まれるか確認する
  3. 3調査者資格証の種類と、調査対象に対する有効範囲を確認する
  4. 4見積に調査、隔離・養生、測定、廃棄、写真記録、完了報告を明記する
  5. 5県・市への届出と労働基準監督署への届出を別々に工程管理する

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04愛媛県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
