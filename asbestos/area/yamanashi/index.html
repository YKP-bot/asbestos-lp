中部 / PREFECTURE GUIDE

山梨県の
アスベスト調査・届出ガイド

山梨県では、建設リサイクル法の届出でも石綿等の有害物質の有無・場所・事前措置を具体的に記載する運用が示されています。補助は県が所有者へ直接交付する一律制度ではなく、市町村事業を通じて実施され、対象の吹付け材が限定されています。

LOCAL DIFFERENCES

山梨県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01山梨県内の建設リサイクル法対象工事。

建設リサイクル届にも石綿情報を具体記載

県の案内では、建設リサイクル法の届出に、石綿など有害物質の有無・種類・使用箇所と、作業場所・搬出経路の確保や事前除去等の措置を記載するよう示しています。環境届と建築届で内容が矛盾しないよう統一します。

根拠[1]
02制度を実施する市町村の対象建築物。市町村ごとの予算、上限、受付期間が優先。

補助は市町村経由で対象建材を限定

県が公表する市町村制度一覧では、分析調査は原則10分の10・1棟25万円上限、除去等は原則3分の2とする枠組みが示されています。ただし対象は吹付け材が中心で、仕上塗材やスレート等は対象外です。

根拠[2]
03県が公表する当該年度の市町村支援事業。

調査と除去で実施市町村が異なる

県の一覧では、分析調査のみ実施する市町村と、除去等まで支援する市町村が分かれています。建物所在地だけでなく、予定している工程が分析だけか除去までかを伝えて確認する必要があります。

根拠[2]

WHERE TO FILE

届出先は工事場所から確定する

大気汚染防止法の届出は工事地を所管する県の林務環境事務所等へ提出します。甲府市など市の所管となる手続は市窓口へ確認し、建設リサイクル法の窓口とも調整します。

根拠[1][2][3]

BEFORE WORK

着手前チェック

  1. 1事前調査結果を建設リサイクル届、石綿事前調査報告、作業計画で一致させる
  2. 2有害物質の種類・場所と、除去時期・搬出経路・仮置場を図面に反映する
  3. 3補助対象が吹付けアスベスト等に限られ、成形板・仕上塗材は対象外となる点を確認する
  4. 4分析だけか除去までかを明確にし、所在地市町村へ契約前に相談する

SUBSIDY CHECK

補助制度は契約・着工前に確認

県公表の一覧に掲載された市町村でも、分析調査と除去等で対応範囲が異なり、年度予算で受付終了となる場合があります。補助決定前の契約・着工は対象外になり得るため、所在地市町村へ先に確認してください。

根拠[1][2][3]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04山梨県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
