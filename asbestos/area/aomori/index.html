青森県の
アスベスト調査・届出ガイド

県の4環境管理事務所と青森市・八戸市の計6窓口に所管が分かれ、県が事前調査から発注者説明、実施届添付、完了確認まで参考様式を一式化している。

LOCAL DIFFERENCES

青森県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01青森県全域

青森市・八戸市は市、それ以外は4環境管理事務所

青森県は届出先と管轄区域を市町村単位で明示している。青森市と八戸市は各市へ、その他は青森、弘前、八戸、むつの環境管理事務所へ提出するため、同じ県内でも最寄りの合同庁舎が提出先とは限らない。

根拠[1]
02青森県所管地域。青森市・八戸市は各市への適用可否も確認

県参考様式が調査・説明・届出添付・完了確認まで連続

県ページには、事前調査記録、事前調査結果票、発注者への説明、実施届とその添付書類、掲示板、作業完了報告の参考様式が掲載されている。工事ごとに別々の書式を作るより、県様式を起点に証拠書類を揃えやすい。

根拠[1]
03青森県の建設リサイクル法対象工事

建設リサイクル法の届出時にも石綿事前措置を確認

青森県の令和7年度アクションプログラムは、建設リサイクル法対象工事の届出時に、事前調査で吹付けアスベスト等の有無を確認する運用を掲げる。大気・労働の手続だけでなく、建設リサイクル法の届出資料との整合も着工前に見直す必要がある。

根拠[2]
04青森県内の特定工事

作業完了時は確認記録を作り発注者へ報告

県は作業完了報告の参考様式を公開し、作業が適切に行われたことの確認記録を作成して発注者へ報告する流れを明示している。写真、点検記録、取り残し確認を施工中から整理しておくと完了報告が滞らない。

根拠[1]

WHERE TO FILE

届出先は工事場所から確定する

青森市内は青森市環境部環境保全課、八戸市内は八戸市市民環境部環境保全課。それ以外は工事所在地により青森・弘前・八戸・むつの各環境管理事務所が担当する。

根拠[1][2]

BEFORE WORK

着手前チェック

  1. 1工事住所を県の管轄表に当て、青森市・八戸市・4環境管理事務所のどこへ提出するか確定する。
  2. 2県参考様式を使う場合も、青森市・八戸市では各市が求める様式・部数・提出方法を再確認する。
  3. 3建設リサイクル法対象工事では、同届出の事前措置欄と石綿事前調査結果の内容を一致させる。
  4. 4完了時に必要な確認記録を、除去前・作業中・除去後の写真計画と点検表に組み込む。
根拠[1][2]

JURISDICTIONS

確認対象の自治体・窓口

  • 青森市
  • 八戸市
  • 弘前市
  • むつ市

掲載名は確認の起点です。法令・条例・建設リサイクル法・補助制度ごとの詳しい管轄は、上記の届出先説明と公式出典を照合してください。

SUBSIDY CHECK

補助制度は契約・着工前に確認

青森県のアクションプログラムは、市町村に国の補助制度活用を促す方針を示しています。補助を検討する場合は、工事所在地の市町村へ対象建材、建物用途、申請年度、契約前申請の要否を確認してください。

根拠[1][2]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04青森県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
