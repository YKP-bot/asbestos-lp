山口県の
アスベスト調査・届出ガイド

山口県では大気汚染防止法の石綿手続を県内各健康福祉センターが地域別に担当し、下関市域は下関市が所管します。岩国・柳井・周南・山口・宇部・長門・萩の各圏域に分かれるため、県庁一括ではなく現場所在地に対応する窓口を先に確定することが重要です。

LOCAL DIFFERENCES

山口県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01山口県内の大気汚染防止法に基づく事前調査結果報告・特定粉じん排出等作業届。

7つの県窓口と下関市に所管が分かれる

県所管区域は市町の組合せに応じて健康福祉センターが異なり、下関市域は市が窓口です。事前調査結果報告システムでの提出先選択や紙届の宛先は、工事住所から環境省の最新窓口一覧を照合します。

根拠[2]
02山口県内で調査者を手配する建築物・工作物の解体等工事。

県内講習情報を資格者確保に利用できる

山口県は県内で開催される石綿含有建材事前調査者講習情報を掲載しています。建築物と2026年からの対象工作物では必要資格が異なるため、着工予定から逆算して調査者の資格証と対応範囲を確認します。

根拠[1][3]
03県内の住宅・共同住宅。個別建材の含有有無は資格者調査で判定。

住宅の吹付け材は築年・構造・劣化状態を分けて評価

県の住宅Q&Aは、平成元年以前の鉄骨造共同住宅で耐火目的の吹付け材が使われる例を示す一方、グラスウール、ロックウール、発泡プラスチック保温材自体は石綿ではないと説明しています。見た目や名称だけで判定せず、図書・現地・必要時分析を組み合わせます。

根拠[4]

WHERE TO FILE

届出先は工事場所から確定する

下関市内は下関市、その他は岩国、柳井、周南、山口、宇部、長門、萩の各健康福祉センターが地域別に大気汚染防止法関係を担当します。労働基準監督署への石綿則手続は別に必要です。

根拠[1][2][3][4]

BEFORE WORK

着手前チェック

  1. 1下関市域か、県の各健康福祉センター所管かを現場住所で確定する
  2. 2建築物・工作物の区分と調査者資格の対応範囲を確認する
  3. 3報告システムの提出先と、特定粉じん排出等作業届の紙提出先を照合する
  4. 4建材名や外観だけで非含有と判断せず、根拠資料または分析結果を残す
  5. 5発注者への説明書、現場掲示、作業完了報告の保存方法を決める

SUBSIDY CHECK

補助制度は契約・着工前に確認

分析・除去支援を利用する場合は、県の一般案内ではなく建物所在地の市町村が当該年度に公開する制度を確認してください。対象建材や着手前申請の条件は制度ごとに異なります。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04山口県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
