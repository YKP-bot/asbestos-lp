山形県の
アスベスト調査・届出ガイド

県が解体・改修向け環境法令チェックシートと一連の参考様式を公開し、届出対象作業は行政への完了報告まで求める。山形市は県4総合支庁とは別窓口。

LOCAL DIFFERENCES

山形県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01山形県全域

山形市と4総合支庁で所管を分担

山形市内の手続は山形市、それ以外は村山・最上・置賜・庄内の各総合支庁環境課が窓口。県庁本庁へ一律に提出する運用ではない。

根拠[1]
02山形県内の解体・改修工事

県独自の環境法令チェックシートと様式一式

山形県は、解体・改修工事向けの環境法令チェックシートに加え、事前調査結果の説明書面、報告書、調査記録、掲示板、作業計画、作業完了報告書までを参考様式一式として公開している。石綿以外の環境手続との漏れ確認にも使える。

根拠[1]
03山形県所管地域の届出対象特定工事。山形市内は市の運用を確認

届出対象作業は行政への完了報告も必要

山形県は、発注者または自主施工者が元請業者から完了報告を受けた後、作業基準の遵守状況と石綿廃棄物の処理状況等を確認するため、特定粉じん排出等作業完了報告書を行政へ提出するよう案内し、専用様式を公開している。

根拠[1]
04村山総合支庁管内

村山総合支庁は現場確認にアスベストアナライザーを活用

令和8年度の村山総合支庁事業概要では、石綿事前調査結果の審査と解体現場への立入検査に加え、アスベストアナライザーによる建材確認、解体現場周辺の一般大気中アスベスト繊維数濃度測定を継続するとしている。

根拠[2]

WHERE TO FILE

届出先は工事場所から確定する

山形市内は山形市。それ以外は村山、最上、置賜、庄内の各総合支庁環境課が工事所在地を担当する。

根拠[1][2]

BEFORE WORK

着手前チェック

  1. 1山形市内か、村山・最上・置賜・庄内のどの総合支庁管内かを住所から確定する。
  2. 2県の環境法令チェックシートを見積・契約前に使い、石綿以外の解体関連手続も同時確認する。
  3. 3実施届の段階で完了報告書の添付資料を確認し、作業基準・廃棄物処理・写真の記録計画を立てる。
  4. 4村山管内では立入検査・現場周辺測定を想定し、調査根拠、作業計画、掲示、飛散防止措置を現場で即提示できるようにする。

SUBSIDY CHECK

補助制度は契約・着工前に確認

山形県内の空き家解体・住宅リフォーム等の支援は、市町村ごとに対象経費が異なります。石綿調査・除去費が対象に含まれるか、契約前申請が必要かを建物所在地の自治体へ個別に確認してください。

根拠[1][2]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04山形県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
