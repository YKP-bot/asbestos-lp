島根県の
アスベスト調査・届出ガイド

島根県の石綿手続は、松江市域だけ松江市、その他の地域は島根県という所管分担が明確です。県は届出対象工事の周辺で大気環境調査も実施しており、施工計画では法定届出だけでなく、隔離・負圧・湿潤化と記録、周辺説明まで一体で準備する必要があります。

松江市域のみ市、その他は県へ報告

事前調査結果は島根県へ報告しますが、工事場所が松江市の場合は松江市へ報告します。吹付け石綿、石綿含有断熱材・保温材・耐火被覆材に係る作業届も同じ所管分担なので、電子報告の宛先を現場住所で確認します。

根拠[1][2]
02県が監視対象とする石綿除去作業。個々の工事で測定が行われるかは所管へ確認。

県が除去工事周辺の大気環境を監視

島根県保健環境科学研究所は、石綿除去作業時の飛散による大気汚染状況を監視するため、作業中の周辺大気調査を実施しています。届出書だけでなく、集じん・排気装置、負圧管理、漏えい時の連絡系統を現場で説明できる準備が重要です。

根拠[3]
032026年1月1日以後に着手する対象工作物等の解体・改造・補修。

工作物調査の資格区分を設備種類ごとに確認

2026年1月から、反応槽、加熱炉、ボイラー、配管設備などの特定工作物では工作物石綿事前調査者が必要となる区分があります。煙突やプラットホーム上家など別の資格でも調査可能な区分と混同しないよう、設備番号から担当資格を照合します。

WHERE TO FILE

届出先は工事場所から確定する

松江市内の事前調査結果報告と特定粉じん排出等作業届は松江市が窓口です。松江市以外は島根県の管轄窓口へ提出します。労働基準監督署への石綿則関係の届出は別系統です。

BEFORE WORK

着手前チェック

  1. 1工事場所が松江市内か、それ以外かを最初に確定する
  2. 2建築物か工作物か、工作物なら告示上の設備区分まで特定する
  3. 3県・市への大防法手続と労働基準監督署への石綿則手続を分けて管理する
  4. 4負圧、集じん排気、湿潤化、漏えい時対応を施工計画と写真記録に落とし込む
  5. 5周辺住民への説明時期と問い合わせ窓口を着工前に決める

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04島根県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
