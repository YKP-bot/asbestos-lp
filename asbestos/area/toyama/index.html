中部 / PREFECTURE GUIDE

富山県の
アスベスト調査・届出ガイド

富山県では、法定の事前調査・掲示・届出に加え、解体等工事に伴うリスクを周辺住民や自治体と共有することが県から明示的に求められています。補助制度は県内一律ではなく、富山市など実施自治体ごとの条件確認が必要です。

LOCAL DIFFERENCES

富山県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01富山県内の石綿除去等工事。具体的な説明方法は所管窓口と周辺状況に応じて判断。

周辺住民とのリスクコミュニケーションを明示

県は、除去工事の届出案内で、周辺住民や自治体との情報共有・リスクコミュニケーションへの協力を示しています。法定掲示だけで足りると決めつけず、住宅密集地や学校・病院の近接地では説明範囲と時期を事前協議するのが安全です。

根拠[1]
02富山市内の対象となる民間建築物。成形板等へ県全体で適用される制度ではない。

富山市の補助は吹付け材に限定

富山市の民間建築物支援は、石綿含有率0.1％超の吹付けアスベスト等を対象とし、除去・封じ込め・囲い込みを支援します。市内限定で、年度末までの完了条件や契約前申請などを事前に確認する必要があります。

根拠[2]
03富山県内で生じる廃石綿等・石綿含有産業廃棄物。

石綿含有廃棄物は分別・別管理を徹底

県の石綿含有廃棄物処理マニュアルは、他の廃棄物との分別、飛散防止、運搬・処分までの区分管理を示しています。除去方法だけでなく、保管場所、表示、委託先の許可範囲、マニフェストまで施工計画に含めます。

根拠[3]

WHERE TO FILE

届出先は工事場所から確定する

富山市内は富山市、その他の区域は富山県の所管窓口へ相談します。大気関係と廃棄物関係で担当が異なる場合があるため、着工前に両方を確認します。

BEFORE WORK

着手前チェック

  1. 1工事場所の所管が富山市か富山県かを先に確認する
  2. 2A3掲示、説明資料、周辺住民への情報提供の要否と時期を着工前に決める
  3. 3石綿含有廃棄物の分別、梱包、保管、運搬、処分先を計画書で一貫管理する
  4. 4富山市の補助を検討する場合は契約・着工前に対象建材と年度内完了条件を確認する

SUBSIDY CHECK

補助制度は契約・着工前に確認

富山市には民間建築物の吹付けアスベスト除去等支援がありますが、富山県全域共通の制度ではありません。その他の市町村については、建築担当窓口に最新年度の制度の有無を確認してください。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04富山県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
