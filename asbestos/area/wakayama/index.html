和歌山県の
アスベスト調査・届出ガイド

和歌山県では、和歌山市と県保健所で所管が分かれます。届出期限を数える『作業開始』には、除去そのものだけでなく足場や隔離養生の設置が含まれると明示されているため、工程表の起点に注意が必要です。県内中小企業には補助ではなく融資制度の可能性があります。

LOCAL DIFFERENCES

和歌山県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01特定粉じん排出等作業の届出対象工事。

14日前の起算日は隔離・足場設置を含む

県の案内は、届出上の作業開始に、石綿除去そのものだけでなく、除去のための足場設置や隔離養生の設置を含むと注意喚起しています。除去日から14日を数えると期限違反になり得ます。

根拠[1]
02和歌山県内全域。

和歌山市と県保健所で提出先が分かれる

和歌山市内は市、それ以外は新宮、田辺、御坊、湯浅、岩出、橋本、海南など工事地を所管する県保健所へ提出します。県の窓口一覧で所在地を照合します。

根拠[1][3]
03制度要件を満たす県内中小企業者。一般住宅所有者向け補助ではない。

中小企業向け対策資金は融資として相談

県は、県内中小企業者によるアスベスト除去等について、環境面の認定窓口と融資窓口を案内しています。給付型補助ではなく返済を伴う制度であり、認定要件と金融条件を別々に確認します。

根拠[2]
04和歌山市内の解体等工事に関する市の周知。

和歌山市は発注者の調査費用負担を明確化

和歌山市は、解体工事の発注者に対し、適正な事前調査に必要な費用を負担し、受注者へ情報提供する責務を周知しています。建設リサイクル届を施工者へ委任しても、発注者の石綿対応責任がなくなるわけではありません。

根拠[4]

BEFORE WORK

着手前チェック

  1. 1除去開始日ではなく、足場・隔離養生の開始日から14日前を届出期限として管理する
  2. 2和歌山市か県保健所のどこが所管するかを現場住所で確認する
  3. 3発注者は既存図面・改修履歴を提供し、適正な事前調査費用と工期を確保する
  4. 4中小企業向け制度を使う場合は、補助ではなく融資であることと認定・返済条件を確認する

SUBSIDY CHECK

補助制度は契約・着工前に確認

和歌山県内の中小企業者には、アスベスト対策を対象とし得る融資制度がありますが、返済不要の補助金とは性質が異なります。給付型支援を探す場合は、建物所在地の市町村へ当年度制度、対象建材、着手前申請の条件を確認してください。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04和歌山県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
