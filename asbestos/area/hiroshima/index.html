広島県の
アスベスト調査・届出ガイド

広島県は県と広島市・呉市・福山市が共同資料を作成し、届出・廃棄物の所管も市域ごとに分かれます。県内一律の宛先ではなく、現場住所から大気、廃棄物、建設リサイクルそれぞれの所管を照合することが、差戻しを防ぐ最重要ポイントです。

LOCAL DIFFERENCES

広島県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01広島県全域。広島市・呉市・福山市の工事は各市情報を優先確認。

県と3市が共同で石綿資料を整備

広島県は広島市・呉市・福山市と共同で、改正法のチラシ、リーフレット、Q&Aを公開しています。県版資料だけでなく、3市域では各市の最新様式と提出方法を合わせて確認する運用が必要です。

根拠[1]
02石綿含有廃棄物・廃石綿等を伴う解体・改修工事。

大気・廃棄物とも3市は別窓口

産業廃棄物の申請・相談は、広島市域、呉市域、福山市域では各市役所、それ以外は県の厚生環境事務所等が窓口です。石綿の飛散防止届と廃棄物処理の相談先を同じだと思い込まず、双方の所管を照合します。

根拠[2]
03県所管区域の公害防止関係申請・届出。市所管区域は各市で確認。

2026年4月から一部申請窓口が変更

広島県は2026年4月から公害防止関係の申請・届出窓口の一部変更を案内し、生活環境保全条例に基づく石綿事前調査結果報告書も掲載しています。過去案件の宛先や社内様式をそのまま再利用せず、最新窓口を確認します。

根拠[3]

WHERE TO FILE

届出先は工事場所から確定する

広島市、呉市、福山市では各市の担当課が主要窓口となり、その他の地域は県の厚生環境事務所・支所等が管轄します。手続の種類によって市へ権限移譲されている範囲が異なるため、工事住所と手続種別の両方で確認します。

根拠[1][2][3]

BEFORE WORK

着手前チェック

  1. 1現場が広島市・呉市・福山市か、県所管区域かを確定する
  2. 2大気汚染防止法、県条例、産業廃棄物の窓口を手続ごとに照合する
  3. 32026年4月以後の最新窓口と様式を使っているか確認する
  4. 4県・3市共同資料と、工事地の市が公開する追加案内を両方確認する
  5. 5廃石綿等と石綿含有産業廃棄物の区分に応じた処理委託先を選定する

SUBSIDY CHECK

補助制度は契約・着工前に確認

補助制度は県内一律ではありません。建物所在地の市町が当該年度に実施する分析・除去支援の有無と、交付決定前着手の扱いを建築担当課へ確認してください。

根拠[1][2][3]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04広島県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
