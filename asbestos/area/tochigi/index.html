関東 / PREFECTURE GUIDE

栃木県の
アスベスト調査・届出ガイド

栃木県では、宇都宮市と県の5出先機関で報告先が分かれます。県の作業手順は、吹付け石綿50平方メートル以上の作業中濃度測定と、濃度測定結果・施工写真・作業記録を添えた作業完了報告を指導事項として示しており、国の届出だけで工程を組むと不足します。

LOCAL DIFFERENCES

栃木県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01栃木県内の解体・改修工事

宇都宮市と県5出先機関に所管が分かれる

事前調査結果の報告先は、宇都宮市、鹿沼・日光、芳賀地域、県北地域、足利・佐野、小山周辺の6区分です。紙で報告する場合は、所管窓口へ正本1部と控え1部を提出します。

根拠[1]
02県の指導基準が適用される、吹付け石綿50平方メートル以上の除去等作業

吹付け石綿50平方メートル以上は作業中の濃度測定

栃木県の除去等作業手順では、吹付け石綿の使用面積が50平方メートル以上の場合に、大気中の石綿濃度測定を行う指導基準が示されています。

根拠[2]
03栃木県の届出対象となる除去等作業。宇都宮市内は市の最新運用も別途確認します。

完了報告に濃度結果・写真・作業記録を添付

県の作業手順は、作業完了報告書に石綿濃度測定結果、施工写真、作業記録を添付する運用を示しています。測定・撮影・記録保存を工事後に準備するのではなく、着工前から工程へ組み込みます。

根拠[2]
04宇都宮市内で市の要件を満たす民間建築物

宇都宮市の除去等補助は令和8年度予算1件

宇都宮市は令和8年度、民間建築物の吹付けアスベスト除去等を対象とする補助を募集し、予算件数を1件、先着順としています。含有調査の補助は平成29年度末で終了しているため、調査費と除去費を混同できません。

根拠[3]

WHERE TO FILE

届出先は工事場所から確定する

宇都宮市内は宇都宮市環境保全課、その他は工事場所に応じて県西・県東・県北・県南の各環境森林事務所または小山環境管理事務所へ報告します。

根拠[1][2][3]

BEFORE WORK

着手前チェック

  1. 1工事住所から宇都宮市または県の5出先機関のどこが所管か確定する。
  2. 2吹付け石綿の施工面積が50平方メートル以上か図面と現地調査で確定する。
  3. 3濃度測定、施工写真、工程別作業記録を見積書と工程表へ含める。
  4. 4紙報告時は正本・控えの必要部数を確認する。
  5. 5宇都宮市の補助を検討する場合は、契約前に当年度の残枠を市へ確認する。
根拠[1][2][3]

SUBSIDY CHECK

補助制度は契約・着工前に確認

宇都宮市は令和8年度の吹付けアスベスト除去等補助を案内していますが、予算件数は1件で先着順です。これは宇都宮市の制度であり、県内全域には適用されません。県内他市町の制度は所在地ごとに確認が必要です。

根拠[1][2][3]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04栃木県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
