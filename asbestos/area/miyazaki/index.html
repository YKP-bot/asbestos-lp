宮崎県の
アスベスト調査・届出ガイド

宮崎県では宮崎市内とそれ以外で大気汚染防止法の窓口が分かれ、宮崎市は独自に分析・除去等の補助を2026年度も案内しています。市補助は1956年から1989年までに施工された民間建築物など独自要件があるため、県全域へ一般化せず所在地と築年を先に確認します。

LOCAL DIFFERENCES

宮崎県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01宮崎県内の大気汚染防止法関係手続。

宮崎市内と市外で届出窓口が分かれる

県の事業者向け案内は、宮崎市内を宮崎市環境指導課、市外を県環境管理課・関係保健所として示しています。事前調査結果報告、特定粉じん排出等作業届、相談先を現場住所から確定します。

根拠[1][2]
02宮崎市内の制度要件を満たす民間建築物。詳細要件と受付状況は市へ確認。

宮崎市は築年等を絞った独自補助

宮崎市の2026年度案内は、市内の1956年から1989年までに施工された民間建築物で、吹付けアスベストのおそれがあるもの等を分析調査補助の対象としています。市外や対象築年外へ同条件を適用できません。

根拠[3]
03宮崎県内の住宅改修・解体。個別の含有有無は資格者調査と必要時分析で判定。

住宅では部位別の候補建材を確認

県の住宅情報は、屋根・外壁の石綿スレート、床のビニル床タイル、天井のけい酸カルシウム板など、住宅で確認すべき候補部位を例示しています。吹付け材だけでなく改修範囲の下地まで調査リストへ入れます。

根拠[1]

WHERE TO FILE

届出先は工事場所から確定する

宮崎市内は宮崎市環境指導課等、市外は県環境管理課・関係保健所が大気関係の窓口です。宮崎市の補助申請は市の建築担当へ行い、市外の建物には適用されません。

根拠[1][2][3]

BEFORE WORK

着手前チェック

  1. 1工事場所が宮崎市内か市外かを確定し、報告・届出先を選ぶ
  2. 2宮崎市補助を検討する場合は所在地、施工年、用途、対象建材を確認する
  3. 3屋根、外壁、床、天井、下地を改修範囲ごとに調査する
  4. 4市補助の申請前に分析や工事へ着手してよいか確認する
  5. 5市外案件は所在地市町村の制度を個別に調べ、宮崎市制度を転用しない

SUBSIDY CHECK

補助制度は契約・着工前に確認

宮崎市の分析・除去等支援は市内建築物に限定され、施工年など独自要件があります。市外案件は建物所在地の自治体へ、宮崎市案件も契約・着手前に最新要綱と予算残を確認してください。

根拠[1][2][3]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04宮崎県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
