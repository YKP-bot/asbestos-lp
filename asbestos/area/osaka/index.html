大阪府の
アスベスト調査・届出ガイド

大阪府は、国法に加えて府条例による追加規制が強い地域です。一定規模以上のレベル3建材工事にも事前届出が必要となり、レベル1・2建材の一定規模以上では敷地境界の濃度測定計画・測定記録も求められます。市町村によって届出先が細かく分かれます。

LOCAL DIFFERENCES

大阪府で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01大阪府条例の適用区域。市条例の有無や様式は提出先へ確認。

事前調査書面を工事完了まで閲覧可能に

府条例は、事前調査結果を記載した書面の写しを工事現場に備え、周辺住民等が工事完了まで閲覧できるようにする仕組みを設けています。掲示には受付番号、元請・下請、飛散防止、測定計画等の追加事項が含まれます。

根拠[1]
02府条例の届出対象区域・対象工事。法のレベル1・2届出とは別に判定。

レベル3建材でも1,000平方メートル以上は府条例届出

石綿含有仕上塗材または石綿含有成形板等の使用面積が、それぞれ1,000平方メートル以上となる工事は、府条例に基づく届出を作業開始14日前までに行います。両者の面積を単純合算せず、建材区分ごとに判定します。

根拠[1][2]
03府条例の対象区域で行う規模要件該当工事。

50平方メートル以上のレベル1・2で濃度測定

吹付け石綿・石綿含有断熱材等の使用面積が50平方メートル以上の工事では、府条例に基づく敷地境界の石綿濃度測定計画と測定・記録が必要となります。適用除外や測定位置・時期は事前に所管へ確認します。

根拠[2][3]
04大阪府内全域。

窓口区分が市町村ごとに細かい

府の届出先一覧は、府環境管理室、各市、広域連携先などに分かれています。大阪市や堺市だけでなく、工事地によって提出先が異なるため、案件ごとに住所照合が必要です。

根拠[4]

WHERE TO FILE

届出先は工事場所から確定する

大阪府内は、府、政令市・中核市、権限移譲市町村などで窓口が分かれます。工事住所を府の届出先一覧に照合し、着工前相談を行います。

根拠[1][2][3][4]

BEFORE WORK

着手前チェック

  1. 1レベル1・2だけでなく、仕上塗材と成形板等の使用面積を区分別に集計する
  2. 214日前届出、閲覧用書面、条例掲示、濃度測定計画を着工前相談で確認する
  3. 350平方メートル基準の対象建材・適用除外・測定位置を所管窓口に確認する
  4. 4工事住所から府・市・移譲先のどこへ提出するかを確定する

SUBSIDY CHECK

補助制度は契約・着工前に確認

大阪府内の補助を検討する場合は、建物所在地の市町村が案内する当年度制度を確認します。対象が吹付け材に限られるか、分析と除去のどちらが対象か、受付期間、予算残額、交付決定前着手の扱いを契約前に照合してください。

根拠[1][2][3][4]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04大阪府の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
