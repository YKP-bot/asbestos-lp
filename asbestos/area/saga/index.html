佐賀県の
アスベスト調査・届出ガイド

佐賀県は、県が直接受け付ける吹付け建材の分析費補助を2026年度も案内し、補助率10分の10・1棟25万円上限を明示しています。さらに県独自の手引と簡易チェックリストを更新しているため、補助申請と飛散防止手続を同じ資料体系で管理しやすい地域です。

LOCAL DIFFERENCES

佐賀県で先に押さえる地域差

適用範囲と根拠を分けて掲載しています。市の制度は県全体の制度として扱っていません。
01県内民間建築物の対象吹付け建材。違法建築でないこと、資格者調査、指定分析方法等の要件あり。

県直接の分析費補助は10分の10・上限25万円

県内の民間建築物で、吹付けアスベスト等のおそれがある建材の分析調査について、補助対象費用の10分の10以内、1棟25万円を上限とする2026年度制度が案内されています。予算内先着順で、申請前相談が必要です。

根拠[2]
02佐賀県内の建築物・工作物の解体、改造、補修工事。

県独自の手引・簡易チェックリストを2026年改訂

佐賀県は解体等工事の石綿飛散防止対策について、県チラシ、簡易チェックリスト、手引を2026年1月版に更新しています。調査、発注者説明、3年保存、電子報告、14日前届をチェック単位で確認できます。

根拠[1]
03佐賀県アスベスト分析費補助。除去費を自動的に含む制度ではない。

補助は除去費ではなく分析費が中心

県の2026年度案内で明示される対象は、吹付け建材の石綿含有の有無を確認する分析調査費です。除去工事費まで同じ県補助で賄えると判断せず、分析後の対策費は所在地自治体や別制度を確認します。

根拠[2]

WHERE TO FILE

届出先は工事場所から確定する

大気汚染防止法の事前調査結果報告・作業届は工事場所を管轄する県窓口へ確認します。分析費補助の事前相談は佐賀県建築住宅課建築指導担当が案内窓口です。

根拠[1][2]

BEFORE WORK

着手前チェック

  1. 1分析前に県建築住宅課へ相談し、申請順序と予算残を確認する
  2. 2対象が吹付け建材で、仕上塗材や成形板を同制度へ混同していないか確認する
  3. 3調査者資格、分析方法、他補助との重複、建築法令適合の要件を確認する
  4. 4県の2026年版チェックリストで調査から完了記録まで確認する
  5. 5分析補助と除去工事費の資金計画を分けて作る

SUBSIDY CHECK

補助制度は契約・着工前に確認

2026年度の分析費補助は予算の範囲内で先着順、募集期限が設定されています。分析機関へ発注する前に県窓口へ相談し、交付決定前着手の扱いと必要書類を確認してください。

根拠[1][2]

COMMON + LOCAL

全国共通ルールと地域手続きを重ねる順序

地域独自の確認だけでなく、資格者による事前調査・報告・作業基準も並行して管理します。
  1. 01工事場所と発注範囲を確定市区町村、解体・改修の範囲、対象建物・工作物を整理します。
  2. 02資格者が事前調査書面・目視を基本に、不明な建材は分析または含有みなしで扱います。
  3. 03全国共通の報告・届出を判定電子報告の規模要件、レベル1・2建材の届出、労働基準監督署側の手続きを確認します。
  4. 04佐賀県の追加事項を反映このページの地域差、窓口、測定、様式、補助条件を工程と見積りへ組み込みます。
  5. 05記録・完了報告まで管理掲示、写真、測定、廃棄物、発注者への完了報告を工事中から残します。
